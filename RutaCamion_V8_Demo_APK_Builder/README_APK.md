# RutaCamión V8 Demo — generar APK

Este proyecto incluye una acción de GitHub que compila automáticamente el APK de prueba.

## Pasos
1. Sube el contenido de esta carpeta a la raíz del repositorio de GitHub.
2. Abre la pestaña **Actions**.
3. Selecciona **Construir APK**.
4. Pulsa **Run workflow**.
5. Al finalizar, abre la ejecución y descarga el artefacto **RutaCamion-debug**.
6. Extrae el ZIP descargado e instala `app-debug.apk` en Android.

En el teléfono puede ser necesario habilitar temporalmente **Instalar aplicaciones desconocidas** para el navegador o gestor de archivos usado.

## Aviso de seguridad
Es un demo. Las rutas, restricciones e incidencias no han sido validadas para conducción real.
